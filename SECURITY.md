# Security

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/KasayoDotCom/identityforge-mcp/security/advisories/new) and include the affected version, reproduction steps, and expected impact. Redact working credentials and personal data from the report.

Security fixes target the latest npm release and the current `main` branch. Use [GitHub Issues](https://github.com/KasayoDotCom/identityforge-mcp/issues) for ordinary bugs and feature requests.
